Sleman
======

Dokumentasi program penandatanganan dan verifikasi software release untuk
Tugas 3 IF4020 Kriptografi.

.. note::

   Tahap 2 sudah menyediakan parser strict untuk bundle dan manifest. Trust store,
   alur verifikasi, dan backend kriptografi belum tersedia.

Quick commands
---------------

- ``sleman --help`` menampilkan seluruh subcommand.
- ``sleman --version`` menampilkan versi program.
- ``make test`` menjalankan smoke test.
- ``make docs`` membangun dokumentasi HTML ini.
